# codestation

Application for learning programming languages through decriptions and quizzes. The quizzes have different types of questions, including questions that require typing code. JDoodle is used for compiling the inputted code. The result of the code as well as its contents are compared to the correct answer. CORS Anywhere is used to solve the CORS errors that would make using JDoodle impossible.

## Tech Stack

**Client:** HTML/CSS/JS, JQuery, Bootstrap

**Server:** PHP

**Database:** MySQL

**Additional libraries, plugins, tools:** Typed.js, Slick.js, JDoodle, CodeMirror, TinyMCE, CORS Anywhere, HTML Purifier
